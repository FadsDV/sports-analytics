# DegenHUB — Feature Reference

> Every page and feature on the site. Use this to understand what exists before adding anything new.

---

## Pages

### Home Dashboard (`/`)

- Lists upcoming, live, and recent games across all sports
- Sport filter tabs (AFL, NBA, Soccer, CS2)
- Game cards showing: teams, score/time, venue
- Clicking a game card navigates to `/game/[id]`

### Game Detail (`/game/[id]`)

AFL, NBA, and soccer games share this route. Sport is detected from the ID prefix.

**Three tabs:**
1. **Overview** — Full match intelligence dashboard
2. **Kitchen** — Bet slip generator
3. **H2H** — Head-to-head history

#### Overview Tab (AFL)

Rendered by `AFLDashboard.tsx` with three modes:

**Pre-match mode** (3-column layout at `lg`):
- **Left** (260px): Home and away squad lists with player headshots
- **Centre**: Match header (teams, kickoff time, venue), form streaks, key stats, weather
- **Right** (240px): Model Pick (predicted margin), Key Edges (matchup insights), Weather (at `2xl:hidden`)

**Live mode**:
- Live score with pulsing indicator
- Quarter-by-quarter score breakdown
- Live player stats table
- SlipTracker showing which bet legs have hit

**Finished mode**:
- Final score display
- Quarter breakdown
- Player stat highlights

#### Overview Tab (NBA/Soccer)

Basic match overview — less analytics depth than AFL. Shows rosters, score, basic stats.

#### Kitchen Tab

See full Kitchen documentation: `docs/KITCHEN_CONTEXT.md`

AFL Kitchen sections:
- **Safe** — 3 legs, 80%+ hit rate
- **Doable** — 3 legs, 68%+ hit rate  
- **Goal Scorers** — 4 legs, goals only
- **Disposals** — 5 legs, disposals only
- **Ballsy** — 3 legs, on-form/bold picks
- **Value Picks** — up to 10 picks, bookmaker edge plays

Each slip card shows:
- Player name (clickable → opens PlayerDrawer)
- Confidence tier badge (ELITE / HIGH / STRONG / RISKY / LONGSHOT)
- Reliability bar (visual percentage)
- Recommended threshold (e.g. "↑ 22+ disposals")
- Odds (if available from The Odds API)
- Average stat, games analysed, edge amount

Value picks grid: `grid-cols-2 sm:grid-cols-3 lg:grid-cols-4`

#### H2H Tab

- Last 10 head-to-head games between the two teams
- VenueFilter: `"all"` | `"home"` | `"away"` filter
- Score, winner, margin for each game
- Win/loss record summary

### Betslip Checker (`/betslip`)

See full documentation: `docs/BETSLIP.md`

Upload any AFL betslip image → AI analyses each leg and rates the overall slip.

- Overall rating: "Good Slip" 🟢 / "High Risk" 🟡 / "WTF who told you this shit" 🔴
- Per-leg rating: SOLID / RISKY / YIKES
- Explanation for each leg

### CS2 Hub (`/sports/cs2`)

Lists CS2 matches in three sections:
- **LIVE** (red accent header) — currently running matches
- **Upcoming** — grouped by date
- **Results** — recent completed matches

Shows: Teams, tournament name, map scores, match format (Bo3 etc.)

Requires `PANDASCORE_API_KEY` — shows "not configured" message without it.

### CS2 Match Detail (`/sports/cs2/match/[id]`)

Basic match info: teams, score, maps played, tournament, scheduled time.

### CS2 Team (`/sports/cs2/team/[slug]`)

Team profile: roster, recent match history.

## UI Components

### PlayerDrawer

AFL-only overlay that appears when clicking a player name in the Kitchen.

Shows:
- Player headshot + name + position + guernsey
- Season averages (D/G/M/T/HO)
- Recent game log (bars per game)
- Reliability scores with confidence tiers
- isOnForm / isBounceBack indicators

Triggered by `onPlayerClick` prop in `AFLKitchen` → `GameDetailTabs.handleKitchenPlayerClick`.

### SlipTracker

Live game feature. Tracks which Kitchen bet legs have already hit during a live game.

A leg is "hit" when the player's live stat ≥ recommended threshold. Shown with a green checkmark.

### VenueFilter

Filter control in the H2H tab. Options: All / Home / Away.

Filters the historical game list to show only games at the relevant venue type.

## Intelligence Features

### Predicted Margin (AFL)

4-factor composite model:
- Attack/defence rating (35%)
- Ladder position differential (30%)
- Recent form — last 5 games (25%)
- Head-to-head record (10%)
- +5 point home ground advantage

Displayed as: **"Richmond +4 pts"** in the Model Pick card.

### Key Edges (AFL)

Matchup intelligence bullets generated by `lib/sports/afl/insights.ts`:
- Venue edge
- Weather impact
- H2H trends
- Form momentum
- Injury/absence signals

### Weather (AFL)

Real-time conditions via BOM (Australian Bureau of Meteorology).

Shows: Temperature, wind, rainfall, condition label.

Hidden for indoor venues (Docklands/Marvel Stadium).

### Reliability Scoring

Sport-agnostic engine at `lib/sports/reliability/engine.ts`.

Formula: `weightedHitRate × consistencyFactor × sampleFactor × minutesFactor + contextualBonus`

Confidence tiers: Elite (≥0.85) / High (≥0.70) / Strong (≥0.55) / Risky (≥0.38) / Longshot (<0.38)

Full details: `docs/KITCHEN_CONTEXT.md`
